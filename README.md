# `tex2png`

A LaTeX document class that can be used to compile equations, diagrams, or any other content to images.
Refer to the [manual](manual.pdf) for more information.
Its [source](manual.tex) shows an example of how to use `tex2png`. The resulting images can be found in the [manual-output/](manual-output) directory.

If you use GraphicsMagick (instead of ImageMagick), you can use the version of `tex2png` in the "gm" branch. However, this version does not support transparent backgrounds, so ImageMagick is recommended.
